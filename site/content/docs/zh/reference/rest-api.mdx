REST API 是接口的事实来源。下面每个端点都由机器可读的 OpenAPI 文档描述——服务端从 handler 注解生成,
地址为 `/openapi.json`。

## 通用约定

- **Base URL**:`https://api.combee.cloud`
- **认证**:除 `/v1/waitlist` 外,每个请求都带 `x-api-key: <key>`;key 以 `cmb_sk_...` 开头。
- **请求 ID**:可选 `x-request-id` 请求头;服务端在每个响应(含错误)中回显。
- **错误**:所有错误使用统一的 `{ "code", "error" }` 结构——见 [Error Codes](./error-codes)。
- **分页**:只有明确说明的端点才返回 `{ items, next_cursor }`(或 `{ keys, next_cursor }`);
  直接返回数组的列表端点不分页。

## Cells

**Cell** 是包含 SQL 和 KV 的逻辑数据空间。REST 路径前缀为 `/v1/databases/...`(历史命名),
但公共概念始终是 Cell。

### 创建 Cell

`POST /v1/databases`

创建一个新的 Cell(懒创建——首次使用前不做磁盘操作)。传 `name` 可以带上人类可读、租户内唯一的名称;
省略时自动生成 `cell-<short-id>`。

**严格创建**:`name` 在账号内已存在时返回 `409 cell_already_exists`。需要幂等的
“存在即复用”,请用[确保 Cell 存在](#确保-cell-存在)。名称必须匹配 `^[a-z0-9][a-z0-9-_]{0,62}$`
(小写字母、数字、`-`、`_`;以字母或数字开头;≤ 63 字符)——否则返回 `400 invalid_cell_name`。

| 参数 | 位置 | 说明 |
|---|---|---|
| `name` | body | 可选;租户内唯一名称(规则见上) |
| `Idempotency-Key` | header | 可选;相同 key 重复调用返回首次创建的 Cell |

响应 `201 Created`:

```json
{ "id": "2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b", "name": "my-app" }
```

错误:`409 cell_already_exists`(名称已被占用)、`400 invalid_cell_name`。

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.combee.cloud/v1/databases \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: cell:my-app" \
      -d '{"name": "my-app"}'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    import { Combee } from 'combee-js';

    const combee = new Combee({
      baseUrl: 'https://api.combee.cloud',
      apiKey: process.env.COMBEE_API_KEY!,
    });

    const cell = await combee.cells.create({ name: 'my-app' });
    console.log(cell.id);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    import os
    from combee import Combee

    combee = Combee(
        base_url="https://api.combee.cloud",
        api_key=os.environ["COMBEE_API_KEY"],
    )

    cell = combee.cells.create(name="my-app")
    print(cell.id)
    ```
  </Tab>
</Tabs>

### 确保 Cell 存在

`PUT /v1/databases/by-name/{name}`

按名称幂等“存在即创建,否则复用”。应用启动推荐用它,而不是严格的[创建 Cell](#创建-cell)。

| 参数 | 位置 | 说明 |
|---|---|---|
| `name` | path | Cell 名称(URL 编码,须匹配 `^[a-z0-9][a-z0-9-_]{0,62}$`) |

响应 `201 Created`(新建)或 `200 OK`(已存在):

```json
{
  "cell": { "id": "2f1c4a0e-...", "name": "my-app", "tenant_id": "9c8b7a6f-...", "state": "idle", "created_at": 1755000000 },
  "created": true
}
```

错误:`400 invalid_cell_name`、`429 quota_exceeded`。

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X PUT https://api.combee.cloud/v1/databases/by-name/my-app \
      -H "x-api-key: $COMBEE_API_KEY"
    # → {"cell": {...}, "created": true} 首次创建
    # → {"cell": {...}, "created": false} 已存在,复用
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const cell = await combee.cells.ensure('my-app');
    console.log(cell.id, cell.name);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    cell = combee.cells.ensure("my-app")
    print(cell.id, cell.name)
    ```
  </Tab>
</Tabs>

### 重置 Cell

`POST /v1/databases/{id}/reset`

清空全部 SQL 与 KV 数据。`id` 和 `name` 保持不变,generation 计数 +1,使过期写入者被拒绝。
破坏性操作——无法撤销。

| 参数 | 位置 | 说明 |
|---|---|---|
| `id` | path | Cell id(UUID) |

响应 `200 OK`——更新后的 Cell 记录。

错误:`500 cell_reset_failed`。

## SQL

### 执行单条语句

`POST /v1/databases/{id}/sql`

对 Cell 执行单条 SQL 语句。读和写语句都接受。

| 参数 | 位置 | 说明 |
|---|---|---|
| `id` | path | Cell id(UUID) |
| `sql` | body | SQL 文本,使用 `?` 位置占位符 |
| `params` | body | 可选;`null` / boolean / number / string 数组,按占位符顺序 |

响应 `200 OK`:

```json
{
  "columns": ["id", "title"],
  "rows": [[1, "Hello"]],
  "rows_affected": 1,
  "truncated": false
}
```

读语句的 `rows_affected` 为 `0`;写语句的 `columns` 和 `rows` 为空数组。

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/sql \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"sql": "SELECT id, title FROM posts WHERE id = ?", "params": [1]}'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const { columns, rows } = await cell.sql.query<{ id: number; title: string }>(
      `SELECT id, title FROM posts WHERE id = ?`,
      [1],
    );

    const result = await cell.sql.execute(`INSERT INTO posts (title) VALUES (?)`, ['Hello']);
    console.log(result.rows_affected);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    result = cell.sql.query("SELECT id, title FROM posts WHERE id = ?", [1])
    # {"columns": [...], "rows": [...]}

    result = cell.sql.execute("INSERT INTO posts (title) VALUES (?)", ["Hello"])
    print(result["rows_affected"])
    ```
  </Tab>
</Tabs>

### 执行事务

`POST /v1/databases/{id}/transaction`

在单个原子单元中执行一组语句——要么全部提交,要么全部回滚。

| 参数 | 位置 | 说明 |
|---|---|---|
| `id` | path | Cell id(UUID) |
| `statements` | body | `{ sql, params }` 对象数组,按顺序执行 |

响应 `200 OK`——每个语句一个结果:

```json
[
  { "columns": [], "rows": [], "rows_affected": 1, "truncated": false },
  { "columns": [], "rows": [], "rows_affected": 1, "truncated": false }
]
```

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/transaction \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "statements": [
          {"sql": "UPDATE accounts SET balance = balance - 100 WHERE id = ?", "params": [1]},
          {"sql": "UPDATE accounts SET balance = balance + 100 WHERE id = ?", "params": [2]}
        ]
      }'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const results = await cell.sql.transaction([
      { sql: `UPDATE accounts SET balance = balance - 100 WHERE id = ?`, params: [1] },
      { sql: `UPDATE accounts SET balance = balance + 100 WHERE id = ?`, params: [2] },
    ]);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    results = cell.sql.transaction([
        {"sql": "UPDATE accounts SET balance = balance - 100 WHERE id = ?", "params": [1]},
        {"sql": "UPDATE accounts SET balance = balance + 100 WHERE id = ?", "params": [2]},
    ])
    ```

  </Tab>

## KV

KV 的值是字符串。key 位于 URL 路径中,必须做百分号编码(SDK 会自动处理)。
操作端点统一放在 `/kv/ops/...` 下,这样任意 key 名也能直接读写。

### 读取值

`GET /v1/databases/{id}/kv/{key}`

| 参数 | 位置 | 说明 |
|---|---|---|
| `id` | path | Cell id(UUID) |
| `key` | path | KV key(URL 编码) |

响应 `200 OK`:

```json
{ "exists": true, "value": "hello", "ttl_seconds": 60 }
```

key 不存在时返回 `{ "exists": false, "value": null }`——**不是**错误。

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/kv/greeting \
      -H "x-api-key: $COMBEE_API_KEY"
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const value = await cell.kv.get('greeting'); // 'hello',缺失时为 null
    const config = await cell.kv.getJson<{ theme: string }>('config');
    ```
  </Tab>
  <Tab value="Python">
    ```python
    value = cell.kv.get("greeting")   # "hello",缺失时为 None
    config = cell.kv.get_json("config")
    ```
  </Tab>
</Tabs>

### 写入值

`PUT /v1/databases/{id}/kv/{key}`

| 参数 | 位置 | 说明 |
|---|---|---|
| `id` | path | Cell id(UUID) |
| `key` | path | KV key(URL 编码) |
| `value` | body | 要存储的字符串值 |
| `ttl_seconds` | body | 可选 TTL(秒);省略 = 持久 key |
| `nx` | body | 可选;仅当 key 不存在时写入 |
| `xx` | body | 可选;仅当 key 已存在时写入 |

响应 `200 OK`:

```json
{ "written": true }
```

`nx` / `xx` 条件不满足时 `written` 为 `false`(空操作,不写入)。

<Tabs items={['curl', 'TypeScript', 'Python']}>

    ```bash
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"value": "hello", "ttl_seconds": 60, "nx": false, "xx": false}'
    ```
  </Tab>
  <Tab value="TypeScript">

### 扫描 keys

`GET /v1/databases/{id}/kv?prefix=&limit=&cursor=`

按字典序列出 keys,可选前缀过滤。

| 参数 | 位置 | 说明 |
|---|---|---|
| `prefix` | query | 可选;只返回以该字符串开头的 key |
| `limit` | query | 可选;每页条数,默认 50,上限 1000 |
| `cursor` | query | 可选;传入上一页的 `next_cursor` |

响应 `200 OK`:

```json
{ "keys": ["greeting", "greeting:2"], "next_cursor": "" }
```

`next_cursor` 为空表示扫描结束。SDK 尚未暴露此端点——请直接调用。

    ```bash
      -H "x-api-key: $COMBEE_API_KEY"
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    // combee-js 尚未暴露,直接调用端点:

    ```
  </Tab>
  <Tab value="Python">
