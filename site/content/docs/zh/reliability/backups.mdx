Combee 把 Cell 数据备份到 S3 兼容的对象存储。

- **快照**:Cell 的一致性时间点镜像。
- **增量**:归档主库 + 当前 WAL,把恢复时间缩短到秒级。

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    # 全量快照
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/backup \
      -H "x-api-key: $COMBEE_API_KEY"

    # WAL 增量
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/backup/incr \
      -H "x-api-key: $COMBEE_API_KEY"
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const backup = await cell.backups.create();           // 全量快照
    const incr = await cell.backups.createIncremental();  // WAL 增量
    ```
  </Tab>
  <Tab value="Python">
    ```python
    backup = cell.backups.create()             # 全量快照
    incr = cell.backups.create_incremental()   # WAL 增量
    ```
  </Tab>
</Tabs>

- 备份存放在 Cell 之外——删除 Cell 不会删除已有备份。
- 恢复见[恢复](./restore)。
- 托管云上自动备份;自托管场景在[对象存储](../self-hosting/object-storage)中配置。
