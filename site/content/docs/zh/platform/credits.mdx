Credits 是 Combee 上的消耗单位。账本只追加(append-only),余额可从交易历史重建。

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl https://api.combee.cloud/v1/credits/balance \
      -H "x-api-key: $COMBEE_API_KEY"

    curl "https://api.combee.cloud/v1/credits/transactions?limit=100" \
      -H "x-api-key: $COMBEE_API_KEY"
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const balance = await combee.credits.balance();
    const { items } = await combee.credits.transactions();
    ```
  </Tab>
  <Tab value="Python">
    ```python
    balance = combee.credits.balance()
    transactions = combee.credits.transactions()
    ```
  </Tab>
</Tabs>

- 金额使用整数最小单位(microcredits)——绝不用浮点数。
- `transactions` 用游标分页(`limit`,默认 100)。
- 在线支付在 v0.1.0-beta **不可用**;充值请用[兑换券](./vouchers)。
