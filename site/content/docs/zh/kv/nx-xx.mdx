---
title: NX / XX
description: set-if-absent 与 set-if-present 条件写入。
since: 0.1.0-beta
status: stable
---

`SET` 支持两种条件:

| 条件 | 行为 |
|---|---|
| `NX` | 仅当 key **不存在**时写入(set-if-absent)。 |
| `XX` | 仅当 key **已存在**时写入(set-if-present)。 |

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    # 仅当 'lock:deploy' 不存在时才写入(SET NX)
    curl -X PUT https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/kv/lock:deploy \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"value": "running", "ttl_seconds": 30, "nx": true}'
    # → {"written": true} 表示获得锁

    # 仅当 'config' 已存在时才更新(SET XX)
    curl -X PUT https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/kv/config \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"value": "v2", "xx": true}'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    // 仅当 'lock:deploy' 不存在时才写入
    const acquired = await cell.kv.set('lock:deploy', 'running', { condition: 'nx', ttl: 30 });
    if (acquired) {
      // 我们持有锁
    }

    // 仅当 'config' 已存在时才更新
    await cell.kv.set('config', 'v2', { condition: 'xx' });
    ```
  </Tab>
  <Tab value="Python">
    ```python
    # 仅当 'lock:deploy' 不存在时才写入
    acquired = cell.kv.set("lock:deploy", "running", ttl=30, condition="nx")
    if acquired:
        # 我们持有锁
        pass

    # 仅当 'config' 已存在时才更新
    cell.kv.set("config", "v2", condition="xx")
    ```
  </Tab>
</Tabs>

条件不满足时写入是 no-op,返回 `false`(什么都不写)。
这是分布式锁与一次性初始化的基础构件。
