每个 Cell 同时提供两种数据模型,共享同一生命周期与隔离边界:

## SQL

SQLite 兼容的关系型数据库,适合结构化数据:

- 表、索引、约束与事务。
- 位置 `?` 占位符的参数化查询。
- 读查询返回 `{ columns, rows }`;写操作返回受影响行数。

完整 API 见 [SQL](../sql/query) 一节。

## KV

Redis-style 键值存储,适合缓存、会话、计数器与功能开关:

- `GET` / `SET`、`MGET` / `MSET`、`DEL`、`EXISTS`。
- `TTL` / `EXPIRE` / `PERSIST` 定时过期。
- `INCR` / `DECR` 原子计数器。
- `NX` / `XX` 条件(不存在才写 / 存在才写)。

完整 API 见 [KV](../kv/get-set) 一节。

两者在每个 Cell 内共享同一个命名空间——SQL 表与 KV 键并存,无需额外配置。
