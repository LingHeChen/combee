Cell 经历一个简单的生命周期:

| 状态 | 说明 |
|---|---|
| **Created 已创建** | 注册元数据;尚无数据。 |
| **Active 活跃** | 收到过请求,持有打开的数据库 / 缓存。 |
| **Idle 空闲** | 一段时间未被访问;释放资源,数据仍然持久。 |
| **Deleted 已删除** | Cell 及其数据被清除(如有备份则保留)。 |

关键行为:

- 创建 Cell 成本很低。`create` 是**严格**的(名称已占用返回 409);幂等的“存在即复用”请用 `ensure`。
- 空闲的 Cell 不产生成本——下次请求会自动重新激活。
- 删除 Cell 不可逆;如有需要先创建[备份](../reliability/backups)。
