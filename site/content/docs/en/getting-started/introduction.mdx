Combee is a **serverless data runtime** for AI-generated apps and lightweight web apps.

Each application gets a **Cell** — a logical data space that provides two things:

- **SQL** — a SQLite-compatible relational database, ready without connection strings or pools.
- **KV** — a Redis-style key-value store with TTL, atomic counters, and `NX` / `XX` conditions.

Cells are cheap to create, have no dedicated container, and only consume resources while active.
You never manage hosts, ports, users, passwords, or connection pools.
