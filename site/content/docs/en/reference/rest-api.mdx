The REST API is the interface source of truth. Every endpoint below is described by the machine-readable
OpenAPI document served at `/openapi.json` (generated from the server handlers).

## Conventions

- **Base URL**: `https://api.combee.cloud`
- **Authentication**: every request (except `/v1/waitlist`) sends `x-api-key: <key>`; keys start with `cmb_sk_...`.
- **Request IDs**: send an optional `x-request-id` header; the server echoes it on every response, including errors.
- **Errors**: all errors use the unified `{ "code", "error" }` shape — see [Error Codes](./error-codes).
- **Pagination**: only endpoints that document it return `{ items, next_cursor }` (or `{ keys, next_cursor }`);
  list endpoints that return a plain array are not paginated.

## Cells

A **Cell** is a logical data space with SQL and KV. The REST path prefix is `/v1/databases/...` for
historical reasons, but the public concept is always a Cell.

### Create a Cell

`POST /v1/databases`

Creates a new Cell (lazy — no disk work until first use). Provide a `name` to create with a
human-readable, tenant-unique name; if omitted, one is generated as `cell-<short-id>`.

**Strict creation**: creating a Cell with a `name` that already exists in your account fails with
`409 cell_already_exists`. For an idempotent "get-or-create", use [Ensure a Cell](#ensure-a-cell).
Names must match `^[a-z0-9][a-z0-9-_]{0,62}$` (lowercase letters, digits, `-`, `_`; starts with a
letter or digit; ≤ 63 chars) — anything else fails with `400 invalid_cell_name`.

| Parameter | Location | Description |
|---|---|---|
| `name` | body | Optional; tenant-unique name (see rules above) |
| `Idempotency-Key` | header | Optional; repeated calls with the same key return the first-created Cell |

Response `201 Created`:

```json
{ "id": "2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b", "name": "my-app" }
```

Errors: `409 cell_already_exists` (name taken), `400 invalid_cell_name`.

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.combee.cloud/v1/databases \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: cell:my-app" \
      -d '{"name": "my-app"}'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    import { Combee } from '@combee/sdk';

    const combee = new Combee({
      baseUrl: 'https://api.combee.cloud',
      apiKey: process.env.COMBEE_API_KEY!,
    });

    const cell = await combee.cells.create({ name: 'my-app' });
    console.log(cell.id);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    import os
    from combee import Combee

    combee = Combee(
        base_url="https://api.combee.cloud",
        api_key=os.environ["COMBEE_API_KEY"],
    )

    cell = combee.cells.create(name="my-app")
    print(cell.id)
    ```
  </Tab>
</Tabs>

### List Cells

`GET /v1/databases`

Returns all Cells owned by the current account. The response is a plain array (not paginated).

Response `200 OK`:

```json

  {
    "id": "2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b",
    "name": "my-app",
    "tenant_id": "9c8b7a6f-...",
```

### Ensure a Cell

`PUT /v1/databases/by-name/{name}`

Idempotent "get-or-create" by name: creates the Cell if it does not exist, otherwise reuses the
existing one. Recommended at application startup instead of strict [Create a Cell](#create-a-cell).

| Parameter | Location | Description |
|---|---|---|
| `name` | path | Cell name (URL-encoded, must match `^[a-z0-9][a-z0-9-_]{0,62}$`) |

Response `201 Created` (new) or `200 OK` (already existed):

```json
{
  "cell": { "id": "2f1c4a0e-...", "name": "my-app", "tenant_id": "9c8b7a6f-...", "state": "idle", "created_at": 1755000000 },
  "created": true
}
```

Errors: `400 invalid_cell_name`, `429 quota_exceeded`.

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X PUT https://api.combee.cloud/v1/databases/by-name/my-app \
      -H "x-api-key: $COMBEE_API_KEY"
    # → {"cell": {...}, "created": true} 首次创建
    # → {"cell": {...}, "created": false} 已存在,复用
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const cell = await combee.cells.ensure('my-app');
    console.log(cell.id, cell.name);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    cell = combee.cells.ensure("my-app")
    print(cell.id, cell.name)
    ```
  </Tab>
</Tabs>

### Rename a Cell

`PATCH /v1/databases/{id}`

Renames the Cell. The `id` is preserved; the new name must be unique in the account.

| Parameter | Location | Description |
|---|---|---|
| `id` | path | Cell id (UUID) |
| `name` | body | New name (must match `^[a-z0-9][a-z0-9-_]{0,62}$`) |

Response `200 OK` — the updated Cell record.

Errors: `409 cell_name_conflict` (name already used), `400 invalid_cell_name`.

### Reset a Cell

`POST /v1/databases/{id}/reset`

Wipes all SQL and KV data. The `id` and `name` are preserved and the generation counter is bumped
so stale writers are rejected. Destructive — there is no undo.

| Parameter | Location | Description |
|---|---|---|
| `id` | path | Cell id (UUID) |

Response `200 OK` — the updated Cell record.

Errors: `500 cell_reset_failed`.

<Tabs items={['curl', 'TypeScript', 'Python']}>

    ```bash
      -H "x-api-key: $COMBEE_API_KEY"
    ```

  </Tab>

## SQL

### Execute a statement

`POST /v1/databases/{id}/sql`

Runs a single SQL statement against the Cell. Read and write statements are both accepted here.

| Parameter | Location | Description |
|---|---|---|
| `id` | path | Cell id (UUID) |
| `sql` | body | The SQL text, with `?` positional placeholders |
| `params` | body | Optional; array of `null` / boolean / number / string, in placeholder order |

Response `200 OK`:

```json
{
  "columns": ["id", "title"],
  "rows": [[1, "Hello"]],
  "rows_affected": 1,
  "truncated": false
}
```

For read statements `rows_affected` is `0`; for write statements `columns` and `rows` are empty arrays.

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/sql \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"sql": "SELECT id, title FROM posts WHERE id = ?", "params": [1]}'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const { columns, rows } = await cell.sql.query<{ id: number; title: string }>(
      `SELECT id, title FROM posts WHERE id = ?`,
      [1],
    );

    const result = await cell.sql.execute(`INSERT INTO posts (title) VALUES (?)`, ['Hello']);
    console.log(result.rows_affected);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    result = cell.sql.query("SELECT id, title FROM posts WHERE id = ?", [1])
    # {"columns": [...], "rows": [...]}

    result = cell.sql.execute("INSERT INTO posts (title) VALUES (?)", ["Hello"])
    print(result["rows_affected"])
    ```
  </Tab>
</Tabs>

### Run a transaction

`POST /v1/databases/{id}/transaction`

Executes a list of statements in one atomic unit — either all commit, or none do.

| Parameter | Location | Description |
|---|---|---|
| `id` | path | Cell id (UUID) |
| `statements` | body | Array of `{ sql, params }` objects, executed in order |

Response `200 OK` — array of results, one per statement:

```json
[
  { "columns": [], "rows": [], "rows_affected": 1, "truncated": false },
  { "columns": [], "rows": [], "rows_affected": 1, "truncated": false }
]
```

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/transaction \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "statements": [
          {"sql": "UPDATE accounts SET balance = balance - 100 WHERE id = ?", "params": [1]},
          {"sql": "UPDATE accounts SET balance = balance + 100 WHERE id = ?", "params": [2]}
        ]
      }'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const results = await cell.sql.transaction([
      { sql: `UPDATE accounts SET balance = balance - 100 WHERE id = ?`, params: [1] },
      { sql: `UPDATE accounts SET balance = balance + 100 WHERE id = ?`, params: [2] },
    ]);
    ```
  </Tab>
  <Tab value="Python">
    ```python
    results = cell.sql.transaction([
        {"sql": "UPDATE accounts SET balance = balance - 100 WHERE id = ?", "params": [1]},
        {"sql": "UPDATE accounts SET balance = balance + 100 WHERE id = ?", "params": [2]},
    ])
    ```
  </Tab>
</Tabs>

## KV

KV values are strings. Keys live in the URL path and must be percent-encoded (the SDKs do this for you).
Operational endpoints live under `/kv/ops/...` so any key name can also be read/written directly.

### Get a value

`GET /v1/databases/{id}/kv/{key}`

| Parameter | Location | Description |
|---|---|---|
| `id` | path | Cell id (UUID) |
| `key` | path | KV key (URL-encoded) |

Response `200 OK`:

```json
{ "exists": true, "value": "hello", "ttl_seconds": 60 }
```

A missing key returns `{ "exists": false, "value": null }` — it is **not** an error.

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    curl https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/kv/greeting \
      -H "x-api-key: $COMBEE_API_KEY"
    ```
  </Tab>
  <Tab value="TypeScript">
    ```ts
    const value = await cell.kv.get('greeting'); // 'hello', or null when missing
    const config = await cell.kv.getJson<{ theme: string }>('config');
    ```
  </Tab>
  <Tab value="Python">
    ```python
    value = cell.kv.get("greeting")   # "hello", or None when missing
    config = cell.kv.get_json("config")
    ```
  </Tab>
</Tabs>

### Set a value

`PUT /v1/databases/{id}/kv/{key}`

| Parameter | Location | Description |
|---|---|---|
| `id` | path | Cell id (UUID) |
| `key` | path | KV key (URL-encoded) |
| `value` | body | String value to store |

`written` is `false` when an `nx` / `xx` condition is not met (no-op write).

### Scan keys

`GET /v1/databases/{id}/kv?prefix=&limit=&cursor=`

Lists keys in lexicographic order, filtered by an optional prefix.

| Parameter | Location | Description |
|---|---|---|
| `prefix` | query | Optional; only keys starting with this string |
| `limit` | query | Optional; page size, default 50, max 1000 |
| `cursor` | query | Optional; pass `next_cursor` from the previous page |

Response `200 OK`:

```json
{ "keys": ["greeting", "greeting:2"], "next_cursor": "" }
```

`next_cursor` empty means the end of the scan. The SDKs do not expose this endpoint yet — call it directly.

<Tabs items={['curl', 'TypeScript', 'Python']}>

    ```bash
      -H "x-api-key: $COMBEE_API_KEY"
    ```
  </Tab>
  <Tab value="TypeScript">

### Set or remove expiry

`POST /v1/databases/{id}/kv/ops/expire`

Body: `{ "key": "a", "ttl_seconds": 60 }`. Omitting `ttl_seconds` (or passing `null`) removes the TTL
(PERSIST). Response `200 OK`:

```json
{ "updated": true }
```

`updated` is `false` when the key does not exist.

<Tabs items={['curl', 'TypeScript', 'Python']}>
  <Tab value="curl">
    ```bash
    # Set TTL to 60s
    curl -X POST https://api.combee.cloud/v1/databases/2f1c4a0e-8d3b-4b2a-9f7e-1c2d3e4f5a6b/kv/ops/expire \
      -H "x-api-key: $COMBEE_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"key": "a", "ttl_seconds": 60}'

    # Remove TTL (persist)

    ```
