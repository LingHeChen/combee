---
title: Object Storage
description: Configure S3-compatible storage for backups and replication.
since: 0.1.0-beta
status: stable
---

Object storage backs Cell backups, restore, and replica pull. Any S3-compatible service works
(MinIO, AWS S3, R2, ...).

| Variable | Description |
|---|---|
| `COMBEE_S3_ENDPOINT` | Endpoint URL, e.g. `http://minio:9000` |
| `COMBEE_S3_ACCESS_KEY` | Access key |
| `COMBEE_S3_SECRET_KEY` | Secret key |
| `COMBEE_S3_BUCKET` | Bucket name (default `combee-backups`) |
| `COMBEE_S3_REGION` | Region (default `us-east-1`) |

The bucket must exist before backups run; the Docker Compose setup creates it automatically
(`minio-init`).

<Callout type="warn">
  Without object storage there are **no backups, no restore, no replication/failover** —
  the replica pulls archives from it.
</Callout>
