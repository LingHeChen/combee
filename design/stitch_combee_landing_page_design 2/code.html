From Instance to Cell

Traditional databases provision heavyweight instances per tenant. Combee provisions lightweight, isolated Cells that activate on-demand, sharing the underlying infrastructure resources securely.

memory

On-Demand Activation

Cells sleep when idle, reducing cost to zero. They wake in milliseconds upon receiving a connection, perfectly matching serverless workloads.

Tenant Isolation

Each Cell is a logically isolated namespace with dedicated access controls. A single physical node can host thousands of secure, isolated Cells.

Cell Lifecycle & Reliability

Data safety is guaranteed through a robust Write-Ahead Log (WAL) architecture.

01 // Primary

Cell handles active read/write traffic. Transactions are committed locally.

02 // WAL Streaming

Changes are continuously streamed via WAL to local disk and replicas.

03 // S3 Backup

Periodic snapshots and WAL archives are securely persisted to S3 storage.

04 // Auto Failover

If a node fails, the Cell is instantly restored on a healthy node from S3 or Replica.
